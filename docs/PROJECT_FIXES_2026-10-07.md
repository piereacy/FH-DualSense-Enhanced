## 本批新增修复

- 更新安装在同一把锁内认领缓存路径、SHA-256 和安装状态。安装期间拒绝新检查、下载，后台检查不能把正在安装的版本换成另一候选。停止服务后不再调度新操作；已经开始的下载仍可完成可复用缓存。
- FH6 语言事务绑定完整 ZIP 内容哈希，在每次移动前后重新校验。外部更新改变文件或插入第三份文件时停止；回滚只移动仍匹配本次事务字节且原路径为空的文件，保留无法确认归属的文件及恢复临时文件。修复入口重新核对两份完整语言包的身份集合。
- 配置保存因并发冲突或写入失败而未完成时，切换配置、删除当前配置和退出会先重试保存。失败则保留当前内存值并提示，不关闭窗口、不调度更新。命名另存能保全调校参数，但不能掩盖仍未保存的应用级设置。
- GUI/TUI 保存失败时保留名称输入，并提供可见错误。另存命名配置后，从真实 Default 快照更新会话基线，避免对未修改过的 Default 错误提示另存。新增错误提示覆盖全部六种非英语语言。
- 清理三处 contextmanager 返回标注的弃用告警。剩余 Pyrefly 警告中 143 项为重复转换提示，另有两处缺少 psutil 类型桩、一处按平台分析的不可达提示及一处冗余条件，未把这些提示认定为已证实的运行故障。
